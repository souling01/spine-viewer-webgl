# Boneview · Spine 骨骼动画离线预览器 — 使用说明

纯离线单文件 HTML，双击即可在浏览器打开，无需联网、服务器或安装；手机 / 平板 / 电脑浏览器通用，推荐 Chrome / Edge。支持 Spine 3.6–4.3（.json/.skel + .atlas + 贴图，可散文件、文件夹或 .zip 导入）。

## 特色功能
- **纯离线零依赖**：所有 Spine 运行时（3.6–4.3）已内联进单个 HTML，断网、file:// 直接打开都能用，不收集、不上传任何文件。
- **多版本兼容**：自动识别 Spine 3.6/3.7/3.8/4.0/4.1/4.2/4.3，容忍后缀名错误（.skel 实为 JSON）、JSON 尾逗号、文件 BOM、缺图部件等非标准导出。
- **多模型浏览与轮播**：列表 / 文件夹两种浏览方式，四种播放模式 + 一键顺序播放全部；切换模型自动继承上次选择的动作与皮肤，缺失再回退默认。
- **动作 / 皮肤混合**：单模型调试时可叠加多个动作轨道、合并多套皮肤。
- **PMA 自动判定**：按图集声明与像素采样自动识别预乘 / 非预乘 / 转预乘，也可手动指定。
- **多主题与背景**：5 套界面主题，棋盘格 / 纯色 / 透明 / 自定义图片背景。
- **低端设备友好**：可切换 30/60 帧率、渲染像素比 DPR、抗锯齿、纹理过滤、初始缩放策略；可选「防卡死保护」在超大导入时主动中止。
- **截图、设置导入导出、快捷键、日志与状态信息**等配套能力。

## 常见问题
- **打开页面 CPU 占用很高 / 风扇响？** 多为浏览器关闭了「硬件加速 / 图形加速」：在浏览器设置开启后重启即可；老旧设备可改用 30 FPS、关闭抗锯齿、DPR 选 1 或 1.5、纹理过滤选最邻近。
- **切 DPR 或转屏后模型大小异常？** 相机统一按屏幕逻辑像素取景，DPR 只影响清晰度；若仍异常点「重置视图」。
- **多贴图模型里某些小部件 / 马赛克页不显示？** 多页图集中尺寸极小（任一边 <100px）的整页贴图会被自动透明处理，属预期；主体大图页不受影响。
- **手机全屏顶部刘海发黑 / 留白？** 安卓 Chrome 沉浸式全屏支持最好；Edge 对全屏接口支持不全可能留黑（其全屏顶部 1px 白线也是 Edge 自身问题）；iPhone 需用 Safari「添加到主屏幕」后全屏。
- **手机选背景图找不到全部相册？** 在系统选择器点「文档」即可浏览所有目录与相册；网页无法改造系统选择器。
- **.skel 打不开 / 报 JSON 或 region 错误？** 程序会自动识别「后缀 .skel、内容实为 JSON」、容忍尾逗号与 BOM、跳过缺失部件；仍失败多为文件损坏或版本不在 3.6–4.3。
- **「从 URL 加载」失败？** 纯网页受跨域（CORS）限制，需要资源服务器允许跨域，否则浏览器会拦截。

## 导入
- 顶栏 / 左栏「导入」：导入文件（json/skel/atlas/png/zip）、导入文件夹、导入 ZIP、从 URL 加载（唯一需要联网的入口，受跨域限制）。
- 电脑端可直接把文件 / 文件夹 / 压缩包拖入页面（一次拖一个文件夹）。
- 模型导入模式：替换 = 先清空再导入；追加 = 保留现有列表再加入；重复同路径文件不重复导入。
- 导入进度框左上角「取消」可随时中止，已读取内容不进列表并释放内存。
- **防卡死保护**（设置里，默认关闭）：开启后会按设备内存对单次导入做容量预检、并在读取中内存过高时自动中止，避免低运存设备卡死或重启；关闭时不拦截任何导入。
- 左栏支持按文件夹结构逐级浏览（点进文件夹、顶部返回）；左栏底部两行显示当前模型「文件夹\文件名」，该路径可手动选中复制，其余界面文字默认不可选中。

## 界面与操作
- 顶栏、左右栏、底部浮动栏在无操作约 2.8 秒后自动隐藏；鼠标移到 / 触摸屏幕最顶或最底的带状区域唤醒。**左栏或右栏打开时，底栏会保持常显**，收起后恢复自动隐藏。
- 全屏时左侧栏保持原开合状态、右侧栏默认收起；左右栏收起后，贴屏幕最左 / 最右边缘点击或触摸可唤出展开按钮。
- 左栏：模型列表、快播（从第一个模型顺序播全部）、搜索、管理（清除全部模型 / 清空当前画面）；列表右侧中部为「定位当前模型」，下滑后右上角出现「回到顶部」。
- 底栏：播放模式、皮肤、动作选择器，上一个 / 播放暂停 / 下一个、重置视图、更多（背景）。选择器展开时底栏保持常显。
- 右侧「菜单」：动作、皮肤、播放（速度 / 混合时长 / 循环）、PMA、运行时、主题背景、调试绘制、设置。

## 播放模式
单动作播放 / 单动作循环（默认）/ 单模型动作循环 / 顺序播放模型列表；左栏「快播」从第一个模型播到最后一个。手动切换模型或点选动作会打断自动轮播并回到单动作循环。切换模型时动作、皮肤参数按「最后一次手动选择」继承，目标模型缺该参数则用默认，之后模型再出现同名参数会继续继承。动作 / 皮肤混合仅在单模型调试使用，与自动轮播互斥。

## 视图与渲染
- 鼠标拖动 / 单指拖动平移（在渲染区域内即可拖动），滚轮 / 双指捏合缩放；R 或重置视图回到初始大小。初始缩放可选：主体优先（默认、不留边距、自动排除游离特效）/ 全部部件 / 动画全程。
- 设置：渲染帧率 60/30、渲染像素比 DPR（自动 / 1 / 1.5 / 2）、初始缩放、纹理过滤（双线性 / 最邻近）、抗锯齿（自动 / 关闭）、防卡死保护、主题、主题背景（棋盘格 / 纯色 / 透明 / 自定义）。
- 快捷键（电脑）：A/S 切换模型，Z/X 切换动作（首尾循环不提示），空格播放暂停，R 重置视图，E 截屏，H/ESC 影院模式。

## 设置与数据
- 设置保存在浏览器 LocalStorage，不清缓存即保留；可导出 / 导入设置，「恢复默认」恢复播放、PMA、调试绘制、导入模式、DPR、初始缩放、防卡死保护、状态信息与日志等（部件筛除及其关键字不被恢复、单独记忆）。
- 状态信息（FPS / DPR / 抗锯齿 / 硬件加速 / Spine 版本 / PMA / 播放模式）与调试日志默认关闭，需要时在设置打开。日志默认停在最新一条，向上滑动可暂停跟随查看历史，滚回顶部恢复跟随。
